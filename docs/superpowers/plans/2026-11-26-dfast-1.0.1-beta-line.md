# DFast 1.0.1 beta line on top of official v1.0.0

Goal: betas install over official v1.0.0 and over each other with no uninstall, never touch the v1.0.0 release or tag, and are pre-releases only.

## Install rules (Android)
- Same applicationId `dfast.app`.
- Same signing key: only tag-triggered release builds use the persistent keystore from repo secrets (cert SHA-256 4553f284...edce). Debug builds use a throwaway key and cannot update over a release.
- versionCode strictly higher than the installed one: official 1.0.0 is 1000799.

## Version scheme (dfast/app/build.gradle)
- versionPatch = 1, versionBuild = N (1..98), isBeta = true. versionName `1.0.1.N-beta`.
- versionCode = 1000800 + N for betas. The official 1.0.1 later uses 1000800 + 99 = 1000899, above every beta.
- Tag `v1.0.1-beta.N` (contains "beta", so the update check treats it as a beta).
- Never reuse or lower a versionCode. Never retag a published beta.

## Workflow change (needed so betas are pre-releases)
- The release step has no prerelease flag, so a tag build would publish a normal release. Add to the softprops step: `prerelease: ${{ contains(steps.tag.outputs.tag, 'beta') }}` and `make_latest: ${{ !contains(steps.tag.outputs.tag, 'beta') }}`. Verify on beta.1 that it is marked Pre-release and v1.0.0 stays Latest.

## Update check change (UpdateUtil.kt tagNameToVersionNumber)
- Current parser strips dots and pads digits. For betas it breaks: beta.10 equals beta.1, beta.2 sorts above beta.10, and a beta of 1.0.1 sorts above the official 1.0.1.
- Replace with a numeric compare of (major, minor, patch, build), where an official release sorts above all betas of the same base. Ship it in beta.1.

## Steps per beta
1. Edit build.gradle (versionBuild, isBeta) and the fixes. Commit to the branch, push (fast-forward).
2. Wait for the branch CI to pass.
3. Create the tag `v1.0.1-beta.N` on that commit, push it over SSH.
4. Check the tag run: the signing step used the persistent keystore, the five APKs share the same cert fingerprint, the release is a pre-release, v1.0.0 is unchanged.
5. Report device-test items honestly: nothing is tested on a device by us.
